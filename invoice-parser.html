🧾 Invoice Line-Item Parser

Status: In Progress

This project automates the extraction and formatting of individual line items from full vendor invoices, making the data analysis-ready for dashboards, spend reports, and product usage reviews.

⚙️ What I Built

  • Script that parses invoices from a formatted input sheet
  • Automatically generates unique IDs and clean column formats
  • Skips duplicates and only logs new invoices intelligently
  • Output feeds into pivot tables and Tableau dashboards

🧰 Tools & Tech Stack

  • Google Sheets + Apps Script
  • Excel formula logic
  • Regex-based data cleaning
