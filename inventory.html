🚚 Inventory Management System

Status: In Progress

This project is a complete Google Sheets-based inventory tracking system built to manage live material counts across four warehouse locations and over 30 service trucks. I designed and implemented this system at my current job to solve issues with stock inconsistencies, poor tracking, and manual data entry errors.

💡 What I Built

  • Fully automated inventory database using Google Apps Script
  • Live synchronization of warehouse and technician stock levels
  • Forecasting tools for seasonal demand using historical trends
  • Transfer logs that track inventory movement across trucks and warehouses
  • Invoice automation that adjusts stock based on incoming shipments

🧰 Tools & Tech Stack

  • Google Sheets + Apps Script (custom functions and triggers)
  • Excel (initial forecasting and transition modeling)
  • Tableau (data visualization + dashboarding)
